# 🛒 E-Commerce Sales & Customer Analytics

An end-to-end data analytics project that analyzes customer purchasing behavior, sales performance, returns, and churn using **Python, SQL, and Tableau**.

This project demonstrates the complete analytics workflow—from data cleaning and exploratory analysis to SQL-based business insights and an interactive Tableau dashboard.

---

## 📌 Project Overview

The objective of this project is to analyze an e-commerce dataset containing **250,000 customer transactions** to uncover valuable business insights related to:

- Sales performance
- Customer purchasing behavior
- Product category performance
- Return analysis
- Customer churn
- Revenue trends

# 📈 Key Business Insights

- 🏠 Home category generated the highest revenue.
- 📅 Revenue peaked in August before declining towards year-end.
- 🔄 Overall return rate remained around **40.6%**.
- 👨‍💼👩‍💼 Male and female customers contributed nearly equal revenue.
- 📦 Revenue contribution across product categories was relatively balanced.
- 📉 Overall churn rate was **20.1%** with minimal variation across categories.
